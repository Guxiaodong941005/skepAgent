* **H5:** `GhCodeHost` no longer hard-codes `github.com`. For an `owner/repo` name, `--hostname`
  is omitted and `gh` uses its configured default host; an https URL still passes its own host.
* **H6:** the bearer rule now accepts a captured value only if it looks generated (a digit, a
  base64 symbol, or mixed case). Prose such as "token verification_failed_for_item" survives.
* **H9:** the IPC client's call deadline, including the wait for a human signature, runs on an
  injected `Clock` (`connectIpc(path, { clock })`, default `systemClock`). The sleep is cancelled
  with an `AbortController` once the exchange settles, and unexpected sleep errors fail the call
  rather than being swallowed. This is the client-only fix the orchestrator allowed;
  `ipc-server.ts` is untouched.
* **H10:** a `rejected`/`dropped`/`failed` verdict goes through `Output.fail`, so the machine line
  has top-level `ok:false`, matching exit 3. The verdict body stays under `result`.
* **H11:** `decodeStatus` accepts only `{ view, extras }` and fails with an actionable message
  otherwise. A daemon `nowMonoMs`, `checkedAtMonoMs` or `fetchedAtMonoMs` is never read; only
  `checkedAgoMs` is, anchored on the CLI's own clock (D23).
* **H16:** RUNBOOK §1.1/§1.3/§3 now describe the Mac human's own CLI home: `~/.skep` with
  `device.toml` + `human_signing_key` and a copy of `allowed_signers`, kept in step with
  rotations. The human key stays in the human's account. The runbook also covers the socket and
  fallback paths, `--socket-group skep` with the group, and `init` not writing the trust root.

## Findings

### Blocking

### Non-blocking

1. **Merge order with SK-612.** The runbook already says "the shipped plist passes
   `--socket-group skep`" and that `skepd` makes `$SKEP_HOME` 0750 group `skep`. Neither is on
   `main` yet; both belong to SK-612. Merge SK-612 before, or together with, SK-614, and check
   that SK-612's directory mode and plist match this text. Otherwise the runbook describes a flag
   that does not exist.
2. **H6 trades a little recall for precision.** A bearer value of a single case with no digits
   or symbols (unusual for generated tokens) is now treated as prose. That is acceptable: the
   specific token rules and gitleaks still apply to code. The rationale is recorded in the
   comment.
3. **The CLI does not inject a clock** (`context.ts` calls `connectIpc(socket)`), so production
   uses `systemClock`. That is the intended default; the fix makes the client testable and
   sim-injectable, which is what H9 asked for.
4. The human's `device.toml` example sets `signing_key` to the human key, because the schema
   requires one. That is fine for the CLI, but `skep doctor` run with that home will report it
   as the "signing key". A later schema change could make `signing_key` optional for a CLI-only
   home (post-MVP).
