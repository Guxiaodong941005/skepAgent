## Verdict: **PASS_WITH_NOTES**

**`CodeMirror`** keeps one daemon-owned bare mirror per **locally allowlisted** repository, at
`$SKEP_HOME/mirrors/<name>.git` (0700, via `safeJoin`).

* Fetch refspecs keep attempt branches out of `--prune`.
* Every git call runs with `core.hooksPath=/dev/null`, so repository content can never trigger a
  hook.
* `createWorktree` checks the branch name (`check-ref-format`, no leading `-`, not `HEAD`, must not
  already exist) and that the base is a fetched **commit**. It then adds a fresh branch at exactly
  that SHA: `base_commit`, or the predecessor's delivered head.
* The `.git` pointer and the mirror's `worktrees/` admin stay daemon-owned. Optionally, only the
  checkout content is handed to the agent user, with `lchown` for tracked symlinks and a sticky,
  daemon-owned root.
* `removeWorktree` preserves dirty attempts unless `force` is set.

**`agentEnv`** builds the agent environment from an **allowlist**: runtime variables only, the
agent user's own `HOME`/`USER`/`LOGNAME`, an optional `TMPDIR`, and the selected CLI's local config
directory variable. It never reads ambient `process.env`. Tests plant `GIT_ASKPASS`,
`SSH_AUTH_SOCK`, `GH_TOKEN` and provider keys and show none of them pass (D19).
**`resolveAgentUser`** resolves uid/gid with literal argv. The notes do not block.

## Findings

### Blocking

None.

### Non-blocking

1. **Agents cannot run git inside their worktree.** The `.git` pointer is 0600 and the mirror is
   0700, both daemon-owned, so `git status`/`git diff` fail for the agent user. That matches PRD
   §11.4 (daemon owns all git) and the SK-207 invocation (`--skip-git-repo-check`). However, coding
   agents often use git to review their own changes. SK-504 should state this in the work prompt,
   or optionally provide a read-only diff (for example in the prompt for fix-ups). The decision
   belongs to SK-504/SK-307's prompt builders; no change is needed here.
2. **`resolveAgentUser` runs `id` with `env: { LC_ALL: "C" }` and no `PATH`.** It works because
   the spawn falls back to a default search path. Use the absolute `/usr/bin/id` (Linux and macOS)
   to make that explicit.
3. **`PATH` is forwarded from the caller-supplied source.** If the daemon's `PATH` contains
   daemon-only directories (for example a directory with credential-helper binaries), the agent
   sees them. Only names are leaked, not secrets, but SK-601 should pass an agent-specific `PATH`
   from `device.toml` or AGENT.md rather than its own.
4. `fetch()` re-runs `init()` (mkdir/chmod + four `git config` writes) on every fetch. That is
   idempotent and cheap, but it rewrites the mirror config each time; a "configured" check would
   avoid unnecessary writes.
