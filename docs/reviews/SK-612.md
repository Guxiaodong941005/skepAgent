## Verdict: **PASS**

H7 / D22 are implemented as specified.

**`IpcServer` options.** `group?: string` and `mode?: 0o600 | 0o660` are validated with Zod: a
strict schema, a group-name regex, and unsupported modes rejected even from untyped callers. The
default is unchanged (directory 0700, socket 0600).

**Start-up order with a group:**

1. The directory is created at 0700, checked to be a real directory (not a symlink), and
   tightened explicitly.
2. Its group is set with `chgrp` (`execFile`, no shell; this uses the OS group database on Linux
   and macOS, including directory services). Failure is an actionable `IpcServerError` and fails
   closed.
3. The server binds while the directory is still 0700.
4. The socket's group is set to the directory's gid, the socket is chmodded to 0660, and **only
   then** is the directory opened to 0750.
5. If anything fails after binding, the server is closed and the socket removed, so a retry
   works.
6. Connections accepted before `running` is set are destroyed.

**`skepd`.** `--socket-group <name>` sets `{ group, mode: 0o660 }`.

**The plist** passes `--socket-group skep`, and its comment explains how to create the group, add
the human's account, and use a fresh login session.

**Consistent with SK-614's runbook:** `--socket-group skep` on the Mac, socket 0660 group `skep`,
`$SKEP_HOME` (the socket directory) 0750 group `skep`, and "the shipped plist passes
`--socket-group skep`" all match this branch. Keys and `device.toml` inside `$SKEP_HOME` keep
their own 0700/0600 modes, so group `skep` can traverse the directory but not read the keys.

### Non-blocking

1. `chgrp` is called as `/usr/bin/chgrp`. That exists on macOS and on merged-`/usr` Linux (e.g.
   Debian 12, current Ubuntu/Fedora), but not on older split-`/usr` systems. It is only used with
   `--socket-group`, which only the Mac plist passes, and it fails closed with an actionable error.
   Acceptable; mention it in the runbook if Linux ever uses the flag.
2. `$SKEP_HOME` is the socket directory, so with `--socket-group` the group can list `$SKEP_HOME`
   (names only). File modes keep contents private. This is intended by D22 and documented by
   SK-614; just noting it.
